# CONTENT STANDARDS
## Human-First Writing System for SEO, GEO, AEO

---

## PRIORITY ORDER

Write for: **Users → Search Engines → AI Answer Engines**

If content genuinely helps users, it ranks. Simple.

---

## WRITING STYLE

Sound like: An experienced professional explaining something clearly.

NOT like: A copywriter, a marketer, or an AI.

| Write This | Not This |
|---|---|
| Clear, direct, practical | Fluffy, vague, generic |
| Short paragraphs (2–4 sentences) | Large text blocks |
| Answer first, then explain | Long intro before the point |

---

## FORBIDDEN PHRASES — NEVER USE

```
In today's digital world
In the ever-evolving landscape
Revolutionary / Game-changing
Unlock the power of / Harness the power of
Cutting-edge / Seamlessly / Elevate your experience
Take your workflow to the next level
Industry-leading / Best-in-class / State-of-the-art
```

If it sounds like AI wrote it, rewrite it.

---

## INTRODUCTION RULE — ANSWER FIRST

❌ Bad:
> "Age calculation plays an important role in modern life..."

✅ Good:
> "An age calculator determines a person's exact age using their date of birth and the current date."

Start with the answer. Always.

---

## CONTENT STRUCTURE

Every important page uses this order:

```
1. Definition       → What is it? (1–2 sentences)
2. Explanation      → How does it work?
3. Examples         → Realistic input/output/explanation
4. Benefits         → Why use it? (user-focused, no hype)
5. Limitations      → Be honest
6. FAQs             → 5–12 questions (see rules below)
7. Summary          → Key takeaways
```

---

## TOOL PAGE CONTENT

Tool is the hero. Content supports it.

Include:
- What the tool does (2–4 sentences max)
- How to use it (3–5 steps)
- 2–5 realistic examples with input → output → explanation
- 5–12 FAQs

Do NOT:
- Write blog-length intros on a tool page
- Add filler to increase word count
- Use marketing language

---

## FAQ RULES

Minimum: **5 FAQs**
Preferred: **8–12 FAQs**

Questions must be:
- Practical and specific to THIS tool
- What a real user would actually ask
- Search-intent driven

Answers must be:
- Direct (answer in first sentence)
- Accurate
- Under 3–4 sentences

Never copy-paste FAQs across pages. Every page needs unique FAQs.

---

## EXAMPLES — MANDATORY

Every page needs examples.

Format:
```
Input:       [what the user enters]
Output:      [what the tool returns]
Explanation: [why / what it means]
```

Use realistic, practical scenarios. Not made-up edge cases.

---

## GEO — AI CITATION READINESS

Structure content so AI systems can extract and cite it.

Use:
- Clear definitions ("X is Y that does Z")
- Numbered lists for processes
- Direct Q&A format
- Tables for comparisons
- Summaries at the end

Avoid vague paragraphs with no extractable facts.

---

## AEO — ANSWER ENGINE OPTIMIZATION

Answer these directly on every tool page:

```
What is it?
How does it work?
Who should use it?
Is it accurate?
Is it free?
How is it different from [alternative]?
```

❌ Bad: "There are many factors to consider..."
✅ Good: "A BMI between 18.5 and 24.9 is considered healthy."

Be specific. Always.

---

## E-E-A-T RULES

- Use accurate information only
- Include real examples
- Never invent statistics, studies, or reviews
- When uncertain → don't make the claim
- Be transparent about limitations

---

## READABILITY

- Target: Grade 6–9 reading level
- Sentences: short and direct
- Paragraphs: 2–4 sentences max
- Use headings, lists, tables for scannability
- Avoid jargon unless the audience is technical

---

## KEYWORD USAGE

- Use keywords naturally where they fit
- Never repeat keywords unnaturally
- Cover the topic fully (semantic coverage matters more than density)
- Focus: user intent first, keyword second

---

## INTERNAL LINKS

Link only when it genuinely helps the user discover something useful.
Never add links just for SEO.

---

## CONTENT DEPTH

- As long as necessary, as short as possible
- Do not add sentences to hit a word count
- Every sentence must earn its place

---

## WHAT TO NEVER WRITE

```
Long introductions that delay the answer
Fluff paragraphs with no information
Keyword-stuffed sentences
Repetitive explanations
Empty statements like "This tool is very useful"
Fake urgency or hype
Unsupported claims or invented facts
```

---

## CONTENT CHECKLIST

Before publishing, verify:

- [ ] Starts with a direct answer or definition
- [ ] No forbidden AI phrases
- [ ] No fluff or filler
- [ ] Examples included (input → output → explanation)
- [ ] FAQs are page-specific (not generic)
- [ ] Easy to scan (headings, short paragraphs, lists)
- [ ] Factually accurate
- [ ] Sounds human
- [ ] Satisfies user intent
- [ ] AI-friendly structure (definitions, Q&A, lists)
- [ ] No keyword stuffing
- [ ] Internal links are genuinely useful

---

## GOLDEN RULE

> Every sentence must earn its place.
> If it doesn't help the user understand, decide, calculate, learn, or act — delete it.
> The best content is not the longest. It's the most useful.
